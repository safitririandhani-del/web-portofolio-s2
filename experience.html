Good morning everyone,

I would like to tell you about my experience in creating a website. For me, making a website was both challenging and exciting because I learned many new things during the process.

When I first started, I did not understand much about web development. I had to learn basic coding such as HTML for the structure, CSS for the design, and JavaScript for interactive features.

At first, it was difficult to remember the codes and understand how they worked together, but I kept practicing and trying.

One of my favorite parts was designing the website interface. I enjoyed choosing colors, arranging the layout, adding icons and images, and making the website look clean and modern.

I also learned how to create a responsive website so it could work properly on both smartphones and computers.

Of course, I faced some problems while creating the website. Sometimes there were errors in the code, buttons did not work, or the design looked messy.

Through this experience, I learned not only about coding but also about patience, creativity, and teamwork.

This experience motivated me to continue learning more about technology and web design in the future.

Thank you.
